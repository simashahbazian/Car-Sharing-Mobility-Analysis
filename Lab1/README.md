 🎯 Overview

This analysis focuses on understanding car-sharing usage patterns through exploratory and statistical analysis of booking and parking data.

The work examines:

- 📊 Booking and parking duration distributions
- 📈 Temporal utilization patterns
- 🕐 Hourly, daily, and weekly usage trends
- 📅 Weekday, weekend, and holiday patterns
- 🧹 Data filtering and outlier removal
- 🔍 Comparison of filtered and unfiltered utilization


 🔎 Analysis

 📊 1. Usage Characterization

Analysis of booking and parking durations using:

- Empirical Cumulative Distribution Functions (ECDF)
- Descriptive statistics
- Comparisons across selected European cities

 🕐 2. Temporal Usage Patterns

Analysis of car-sharing utilization across different time scales:

- Hourly patterns
- Daily patterns
- Weekly patterns
- Weekday vs. weekend behavior
- Holiday periods

 🧹 3. Outlier Filtering

Defined filtering criteria for booking and parking durations to reduce extreme observations and improve the quality of subsequent analysis.

 📈 4. Filtered vs. Unfiltered Analysis

Compared utilization patterns before and after filtering to evaluate the effect of the data-cleaning criteria.

 📐 5. Statistical Analysis

Computed descriptive statistics including:

- Mean
- Median
- Standard deviation
- Percentiles

for booking and parking duration data.
