 🚗 Car-Sharing & Urban Mobility Data Analysis

 📍 Politecnico di Torino | 🎓 ICT for Smart Mobility | 👥 Group 13


 🎯 Project Overview

This project analyzes **car-sharing and urban mobility data** in Torino and other European cities as part of the ICT for Smart Mobility course at Politecnico di Torino.

The project covers:

- 📊 Exploratory mobility analysis
- 🧹 Data filtering and outlier removal
- ⏱️ Temporal usage patterns
- 🗺️ Origin-Destination (OD) matrices
- 📐 Mobility similarity analysis
- 👥 Behavioral segmentation
- ⚡ Electric Vehicle (EV) simulation

> 👩‍💻 **Group Project — Individual Contribution**  
> This repository presents the analytical components independently developed by **Sima Shahbazian**.



 🔍 My Contribution

My work covered analytical components across **Lab 1, Lab 2, and Lab 3**.

 1️⃣ 🚗 Car-Sharing Usage Analysis

- 📈 Analyzed car-sharing usage patterns across different cities.
- ⏱️ Examined booking and parking durations using descriptive statistics and empirical distributions.
- 📅 Analyzed hourly, daily, weekly, weekday/weekend, and holiday usage patterns.
- 🧹 Applied data filtering and outlier removal to improve data quality.
- 🔄 Compared filtered and unfiltered utilization patterns.


 2️⃣ 🗺️ Origin-Destination Matrix Analysis

- 🧩 Constructed and analyzed **Origin-Destination (OD) matrices** for different temporal conditions.
- 📅 Compared mobility patterns across:
  - Weekdays vs. weekends
  - Daytime vs. nighttime
  - First week vs. second week
  - Car2Go vs. Enjoy
- 📐 Applied multiple distance metrics:
  - Manhattan Distance (SAD)
  - Euclidean Distance
  - Maximum Norm
  - Spectral Norm
- 🔥 Used heatmaps and matrix-based analysis to examine spatial mobility patterns.


 3️⃣ 👥 Behavioral Segmentation

- 👤 Analyzed mobility behavior across demographic and trip-related characteristics.
- ⚧️ Compared mobility patterns based on:
  - Gender
  - Age groups
  - Travel motivation
- 🔄 Compared behavioral patterns across different mobility datasets and car-sharing services.



 4️⃣ ⚡ Electric Vehicle Mobility Simulation

- 🛣️ Analyzed trip distance, trip duration, and their relationship across different road types.
- 🧹 Applied data-quality and outlier filtering to mobility trajectories.
- 🔋 Developed a trip replication and EV simulation workflow.
- 📊 Evaluated EV trip feasibility based on:
  - State of Charge (SoC)
  - Energy consumption
  - Parking time
  - Charging opportunities
- 🚘 Compared different EV models under **AC and DC charging scenarios**.
- 💶 Analyzed charging cost, remaining SoC, energy consumption, and feasible/unfeasible trips.
